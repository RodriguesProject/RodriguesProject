# 04 — Checklist de materiais a adquirir

## Finalidade

Organizar a necessidade de aquisição desde a identificação do material até a conferência do recebimento, mantendo ligação com o catálogo mestre.

## Campos recomendados

| Campo | Descrição |
|---|---|
| ID da solicitação | Identificador único da necessidade |
| Data | Data do registro |
| Obra | Obra ou centro de custo solicitante |
| Solicitante | Responsável pela requisição |
| SKU / código de origem | Identificação do material |
| Descrição / especificação | Nome e variante do catálogo |
| Unidade de controle | Unidade validada para a operação |
| Quantidade | Quantidade requerida |
| Prioridade | Baixa, normal, alta ou urgente |
| Fornecedor | Casas d'Água, Balaroti, Cassol ou Pedra Boa |
| Cotação | Preço unitário, data e observações |
| Aprovação | Pendente, aprovado ou reprovado |
| Pedido | Número, data e situação |
| Entrega | Previsão, quantidade recebida e saldo a receber |
| Conferência | Quantidade e qualidade verificadas |

## Checklist do fluxo

- [ ] Necessidade identificada pela obra ou responsável pelo estoque.
- [ ] Material localizado no catálogo.
- [ ] Código e especificação conferidos.
- [ ] Unidade de controle confirmada.
- [ ] Quantidade solicitada definida.
- [ ] Prioridade registrada.
- [ ] Fornecedor selecionado.
- [ ] Cotação obtida e registrada.
- [ ] Compra aprovada por responsável autorizado.
- [ ] Pedido emitido e número registrado.
- [ ] Prazo de entrega acompanhado.
- [ ] Material recebido e quantidade conferida.
- [ ] Qualidade/especificação conferida.
- [ ] Entrada lançada no estoque correspondente.
- [ ] Solicitação encerrada ou saldo pendente atualizado.

## Fornecedores da lista inicial

- Casas d'Água
- Balaroti
- Cassol
- Pedra Boa

A indicação do fornecedor não significa exclusividade, disponibilidade, preço vigente ou aprovação comercial. Dados comerciais devem ser confirmados em cada aquisição.

## Controles gerenciais

- solicitações em aberto;
- cotações pendentes;
- compras aguardando aprovação;
- pedidos emitidos;
- entregas parciais;
- pedidos em atraso;
- itens recebidos sem conferência;
- valor estimado das aquisições, quando houver cotações registradas.
